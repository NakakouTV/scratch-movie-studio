# Scratch Movie Studio

Scratch Foundationの公式エディタ **@scratch/scratch-gui 15.1.1** をローカルで動かし、HTTP APIで編集操作をアニメーション付きで実行するツールです。sb3から制作手順を生成して、空のコード領域から組み立てる動画を作れます。AIエージェントは含みません。

## 起動

GitHubから取得した場合は、最初に `npm ci` と `npm run setup` を実行してください。Node.js、Google Chrome、FFmpegが必要です。セットアップ後は次の手順で起動します。

1. `起動.cmd` をダブルクリック（または `npm start`）。
2. ブラウザで http://127.0.0.1:8601 を開く。
3. sb3を選択し、「制作アニメーションを生成」を押す。
4. 完成したMP4、sb3、操作手順、検証レポートを保存する。

処理には専用のChromeを使用します。普段のChromeプロファイルには接続しません。サーバーを起動した端末を閉じるとツールは終了します。

## 動作環境・再セットアップ

- Windows、Node.js 18以上、Google Chrome、FFmpeg（libx264を含むビルド）
- 初回取得時のみネットワークが必要です。
- `npm install` → `npm run setup` → `npm start`
- Edgeを使う場合は環境変数 `BROWSER_CHANNEL=msedge`。
- FFmpegがPATHにない場合は `FFMPEG_PATH` に実行ファイルのパス。
- ポートは `PORT` で変更可能（既定8601）。

公式エディタは版を固定し、ローカル配布物から読み込みます。Scratchサイトのアカウントへのログインや公開操作は行いません。

リポジトリにはソースコードと、このツール用に生成した `PEN動作確認.sb3` を含めています。公式エディタ本体、依存ライブラリ、生成動画、検証結果、利用者が読み込んだ作品は含めません。長方形描画・Grid作品などを使う回帰テストは、対応するsb3を別途ローカルに用意して実行してください。以下の検証記録にある動画・結果のパスは、開発時のローカル出力先です。

## 標準の動画生成

- 日本語の公式Scratch画面、1920×1080、30fps、H.264 MP4（実行音はAAC）。
- カーソル表示あり、クリック波紋なし。
- カテゴリをクリックし、パレットをスクロールし、ブロックを実際にドラッグ＆ドロップ。
- パレットから配置先へは直線でドラッグ（開始・終了は滑らかに加減速）。既存ブロックの移動で両端が最小倍率でも画面に収まらない場合は、画面内で途中まで運び、スクロールして移動を続けます。
- APIが指定したブロック・入力欄だけをスナップ先にするため、隣の入力欄への吸着を防ぎます。スクロール完了後にドラッグ元を確認します。
- 変数・リスト・定義を公式ダイアログで作成。
- 定数・名前を1文字ずつ入力。定義の引数は定義ブロックからドラッグ。
- コスチューム（背景）・音タブを開き、公式アップロードメニューから素材を1つずつ追加。元の名前・順番・画像の中心位置・選択中のコスチュームを復元。
- スプライト本体と拡張機能は撮影開始前に準備。
- 左のパレット・右下の拡大縮小ボタン・画面下端を避けて、操作できる位置に表示を移動。長いブロックは接続する位置を表示。
- メッセージ名は完成プログラムに残る送信・受信ブロックで作成。スクロールする選択メニューにも対応。
- 操作速度と、完成後の実演時間を設定。
- 完成したブロック構造、定数、変数・リスト、素材を比較。違いがある場合は失敗として報告。
- 操作手順JSON、操作ログ、失敗時の画面を保存。

sb3に制作履歴はないため、構造から手順を生成します。定義を先に作り、各スクリプトの上から、入れ子をたどって組み立てます。変数・リストの初期値は作成後に復元します。素材追加を省きたい場合はジョブAPIに `animateAssets: false` を指定します。

## API

ブラウザで `/api.html` を開くと操作例と対応一覧を確認できます。

```
POST /api/projects                       sb3バイナリを読み込む
POST /api/jobs                           sb3再構築・録画を開始
GET  /api/jobs/:id                        進捗、検証、成果物URL
POST /api/sessions                       個別操作用のエディタを作成
POST /api/sessions/:id/actions            編集操作を実行
POST /api/sessions/:id/recording/start     録画開始
POST /api/sessions/:id/recording/stop      録画停止・MP4化
GET  /api/sessions/:id/project.sb3         保存
GET  /api/capabilities                    対応状況
```

CLI: `npm run render -- "project.sb3" 1`（先にサーバーを起動）。

APIはlocalhost限定です。同時に複数の命令で同じエディタを操作しないようロックします。命令は完了後に結果を返します。動画生成はジョブIDを返し、進捗を別途取得します。

## 初期版の制限

- アップロードボタンの操作と素材の表示を収録します。OSのファイル選択ダイアログは収録対象外で、素材ファイルは自動選択します。
- ペイント・音声の詳細編集、コメント作成アニメーション、クラウド・ハードウェア拡張の操作は未対応。
- Scratchの音声出力を収録します。OSの通知音やマイク音声は含みません。
- UIアニメーションは実時間録画です。30fpsで出力しますが、PCの負荷により操作・画面更新が遅くなる場合があります。
- ブロック・変数・引数の内部IDと配置座標は元のsb3と異なる場合があります。検証は接続と内容を比較します。
- 変数・リストのモニター表示と位置は作成時に復元します。その他のモニターやコメントは現時点で復元対象外です。
- 全てのScratch作品に対して動作を保証するものではありません。未対応のブロックや入力を検出すると停止し、ログを出します。
- APIの接続先指定はドラッグ中だけ有効で、終了・失敗時に通常のスナップへ戻します。接続できない型や不正な指定はエラーになります。[スナップ修正の記録](docs/known-issues.md) を参照してください。
- 失敗・中止時は最後の保存地点から再開できます。完成MP4には正常保存済みの区間と再開後の区間だけを結合します。
- ジョブ履歴・保存地点・元の素材は `outputs/<job-id>/` に保存し、サーバー再起動後も復元します。旧版ジョブと直接のマウス・キー入力を含む独自手順は途中再開できません。
- ブラウザの録画フレームはジョブの `segments/<segment-id>/frames/`（個別録画は `frames/`） に保存されます。長い動画ではディスク使用量が増えます。

## 構成

- `web/` 管理画面・公式エディタの埋め込み・版固定の接続アダプター
- `web/workspace-geometry.js` 画面の操作可能範囲・スクロール・ドラッグ元の当たり判定
- `web/asset-import.js` 公式アップロードで元の素材データを保持するアダプター
- `web/snap-target.js` APIドラッグ中だけ接続先を限定する版固定アダプター
- `server/controller.mjs` マウス・入力・公式ダイアログ・ブロック接続API
- `server/project.mjs` sb3解析、手順生成、プログラム比較
- `server/recorder.mjs` 画面フレームと時刻を記録し、FFmpegで30fpsに変換
- `server/api.mjs` セッションと録画ジョブ
- `vendor/package/` 公式エディタの配布物（ソース・ライセンスを含む）

## テスト

- `node tests/full-project.mjs "project.sb3" result-name` 素材追加から全ブロック構築、完成比較、素材バイト列、実行時のモニター名を検証（結果は `test-results/full-projects/result-name/`）
- `node tests/monitor-labels.mjs` スライダー・全体変数・ローカル変数・リストの名前と、実行中の表示切替・保存後の再表示を検証

- `npm test` sb3解析・手順順序・差分検出のテスト
- `npm run test:integration` 元サンプルを公式エディタで再構築して比較（サーバー起動が必要）
- `node tests/integration.mjs PEN動作確認.sb3` PEN・リスト・ローカル変数のテスト
- `node tests/api-session.mjs` HTTP API経由の個別編集・真偽値引数・録画のテスト
- `node tests/socket-regression.mjs` 入れ子へドラッグする際の誤接続の回帰テスト
- `node tests/targeted-snap.mjs` 接続先指定・速度差・移動・引数の複製・例外時の復元のテスト
- `node tests/integration.mjs "4×4 Grid Renderer ver12 1costume (1).sb3"` 誤スナップが起きた作品の全体再構築・比較
- `node tests/far-drag.mjs` 画面外に遠い接続先への中継移動・下方向への移動・復帰
- `node tests/special-field-tabs.mjs` 素材タブからの色設定APIを検証
- `node tests/special-fields.mjs` 色・角度・数値・各種メニュー・停止ブロックの形変更と保存後の値を検証
- `node tests/broadcast-input.mjs` メッセージ送信の短縮形式・選択操作・旧手順のタイムアウト回帰テスト
- `node tests/input-first-drag.mjs` 入力欄から始まる文字列演算ブロックの追加・入れ子・移動
- `node tests/interaction-regression.mjs` 左・右下・下端の遮蔽、下方向の配置、長いCブロック、パレット・メニューのスクロール、実ブロック上のメッセージ作成
- `node tests/assets-integration.mjs [project.sb3]` 素材追加付きの再構築・素材バイト列の比較
- `node tests/make-assets-fixture.mjs` 複数の画像・背景・音の検証用sb3を生成
- `node tests/monitor.mjs` 変数モニターのスライダー設定の復元テスト

## 作成済みのサンプル

- `outputs/素材追加と操作修正サンプル.mp4` 背景・SVG/PNGコスチューム・音の追加を含む最新版（2倍速、約82秒）。36操作と完成データの比較に合格。

- `outputs/サンプル_長方形描画.mp4` 元のsb3を132操作で再構築した動画（確認用4倍速、約2分18秒）
- `outputs/サンプル_PEN.mp4` PENの色・太さ・繰り返し・変数・リスト・音を含む確認用動画（約38秒）

いずれも1920×1080、30fps、H.264/AACで出力済みです。再構築したプログラムの比較は合格しています。詳細なログ・sb3・検証レポートは、各動画を作成した `outputs/<job-id>/` に残しています。

## 途中保存・再開と倍率制御

- 制作中の「途中保存して一時停止」で、現在の操作の完了後に保存します。「保存地点から再開」で続行します。
- 25操作ごと、対象切替、素材追加後にも自動保存します。エラー時は最後の保存地点まで戻って未保存区間だけを撮り直します。原因が解消されていない場合は再度停止します。
- アプリを再起動した後は「制作履歴」から選べます。保存地点のsb3もダウンロードできますが、途中再開にはID対応表等も必要なので、出力フォルダ全体を残してください。
- 録画は保存地点ごとの区間に分け、完成時に結合します。保存・復元処理の待ち時間は収録せず、再開位置はカットの切れ目になります。
- 「ブロックの倍率下限」は80%が初期値です。100%または従来相当の30%も選べます。遠い場所へは中継ドラッグで移動します。
- APIの設定と制限は管理画面のAPIリファレンスを参照してください。
- `node tests/checkpoint-resume.mjs` 保存・復元・追加後の故意の失敗・再起動後の再開・完成比較を検証。
- `node tests/checkpoint-resume.mjs --record` 素材追加直後の停止から再開し、録画区間の保持、結合したMP4の音声・映像・長さを検証。

## 場面別の動画出力

- 「動画の分け方」で「全体＋場面別」「場面別のみ」「全体のみ」を選択できます。
- 読み込んだ作品を、素材追加・変数とリスト・定義作成・各スクリプトの組み立てに自動分割します。「出力する場面」で名前と出力対象を編集できます。
- 完成後の実演を設定すると、その映像も独立した場面として保存します。
- 完成後、各場面を個別にダウンロードし、再生欄のメニューで切り替えられます。場面一覧と操作範囲は `scenes.json` に保存します。
- 未選択の場面も操作は実行します。後続の場面に必要な素材・変数・定義を準備するためです。全体動画には全操作を収録します。
- APIでは `outputMode: "both"` と `scenes: [{title, from, to, enabled}]` で自由な操作範囲を指定できます。詳細は管理画面のAPIリファレンスを参照してください。
- `node --test tests/project.test.mjs tests/scenes.test.mjs` 自動分割・範囲指定・既存の再構築処理を検証。
- `node tests/checkpoint-resume.mjs --record --scenes` 場面途中の一時停止と故意の失敗から再開し、全体・場面別MP4の30fps、音声、区間の重複・混在がないことを検証。
