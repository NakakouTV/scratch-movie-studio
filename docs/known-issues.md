# 不具合の修正記録

## 入れ子の入力欄にドロップしたときの誤スナップ

状態: 解決済み。2026-09-24に修正を実装し、ユーザーから全て直ったとの確認を受けた。

対象: `4×4 Grid Renderer ver12 1costume (1).sb3`、参照動画 `movie2.mp4`（ローカルの検証資料）。

元の失敗記録: `outputs/b33743d5-505e-49ec-86b8-9ac2876a5669/log.json`。127操作中の36操作目で、`operator_add` を `data_itemoflist` の `INDEX` 入力に入れる操作が接続検証に失敗している。リストの項目ブロックは `motion_gotoxy` の `X` 入力に入っている。

2026-09-24に変更前のコントローラー、drag=750msで再現。マウスを離す直前の候補は、上の段の `operator_divide` の `NUM2`（もとの定数7）になっていた。結果も「＋」がそこへ接続されている。診断記録は `test-results/snap-diagnosis.json`、画像は `test-results/snap-diagnosis.png`。drag=650msの別試行では成功したため、経路上のマウスイベントの間隔によっても結果が変わる。直線移動でこの問題まで解消したとは判定していない。

使用中の公式配布物のソースマップで、Blocklyの `BlockDragStrategy` は接続点の距離で候補を探し、`currCandidateIsBetter` / `currentConnectionPreference` によって直前の候補を優先することを確認した。ドロップ時の `applyConnections` はその候補を接続する。見た目の重なりだけで最終的な接続先は決まらない。挿入プレビューによる配置の変化や、ツール側の座標計算も区別して診断する必要がある。

## 実装した対策

`web/snap-target.js` に版固定のアダプターを分離した。`block.add` / `block.move` のドラッグ中のみ、指定されたブロックID・入力名に対応する接続だけを候補にする。目的地に到着してマウスを離す前に候補を確定し、公式のプレビュー・型チェック・ドロップ・イベント処理を使って接続する。接続先の指定がない座標配置ではスナップしない。

新規ブロックと既存ブロックの移動、定義からの引数複製に対応する。例外時はドラッグを取り消し、成功・失敗とも `finally` で元の候補探索処理を復元する。通常のマウス操作や他のワークスペースは対象外。公式配布物のファイル自体は変更していない。

録画中の検証で、パレットの非同期スクロール中に座標を読み取ると別のブロックをつかむ問題も判明した。スクロール完了を待って計測し、マウスを押す前に対象がカーソル下にあることも確認するようにした。

## メッセージ送信ブロックで文字入力欄を待ってタイムアウト

2026-09-24、迷路作品の `outputs/f61728ee-8170-4f72-b071-eb2800cf22dd/log.json`、114/742操作目で発生。sb3の短縮形式 `[11, メッセージ名, ID]` を通常の文字定数と同じ `block.input` に変換していた。実際のフィールドは選択メニューのため、`input.blocklyHtmlInput` が開かず10秒でタイムアウトした。

手順生成では形式11を `block.field` / `BROADCAST_OPTION` に変換し、メッセージIDも引き継ぐ。旧手順との互換性のため、コントローラーの `block.input` も実フィールドがドロップダウンならメニュー操作へ振り分ける。待ち時間の延長は行わない。

`tests/broadcast-input.mjs` に送信・送って待つ・受信、既存名の選択、新しい名前の作成、計算ブロックの背後に保持するメッセージ、保存形式の意味比較、旧手順互換の検証を追加した。


## 最小倍率でも移動元と接続先が同時に表示できない場合の接続失敗

2026-09-24、`3D(8)空間移動.sb3` の `outputs/046cb264-a9bf-403e-9bce-66acaca21e76/log.json`、489/1151操作目、引数x2を多重の計算式へ接続する場面で発生。横に長い式を持つ定義呼び出しで再現した。最小倍率0.3でも両端が画面内に収まらず、画面外でマウスを離していたため、確定予定の接続が実行されなかった。

同時表示できない場合は、操作可能な領域内の途中地点へ一度置き、ドラッグを終了してからスクロールし、続きの直線移動を行う。最後のドラッグだけを指定先に接続する。ドラッグ中はスクロールしない。引数複製の仮置き地点も固定のワークスペース座標ではなく、その時点の画面内から選ぶ。

`tests/far-drag.mjs` で、横に長い定義呼び出しへの引数追加、y=18000への移動、元の入力への再接続を検証する。各マウスアップの座標がコード領域内であることも確認する。64回の中継で到達しない極端な距離は明示的なエラーで停止する。


## ペンの色を通常メニューと誤判定
