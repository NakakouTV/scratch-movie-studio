# 場面別動画出力

制作設定の「動画の分け方」で、全体＋場面別、場面別のみ、全体のみを選ぶ。作品の読み込み後、「出力する場面」で名前と出力対象を変更できる。生成完了後は各場面の保存リンクと再生選択メニューを使う。

自動分割は対象ごとの素材追加、変数・リスト、定義の作成、各スクリプトの組み立て。完成後の実演を指定した場合は独立した最後の場面になる。APIでは1始まりの操作範囲を指定できる。個別出力しない場面も操作は実行し、後続の依存関係を保つ。場面の並べ替えや前提操作の省略は行わない。

録画区間に場面IDを付け、場面の境界でも保存する。途中保存に区間と場面IDの対応を含め、再開時には未保存の失敗区間を破棄する。出力先は `scenes/001.mp4` 等の連番で、名前・操作範囲・区間・概算秒数は `scenes.json` に記録する。場面名をファイルパスとして使用しない。

## 検証

- 既存の再構築テスト10件と、場面の自動分割・不正範囲検出2件に合格。
- PEN作品31操作で、コスチューム追加後に一時停止してディスクから復元。続いてブロックが追加された後に故意の例外を発生させ、保存地点から再開。完成したコード・素材が元作品と一致。
- 全体MP4と5本の場面別MP4（実演を含む）について、30fps、音声、映像のデコード、収録時間との整合性を確認。
- 非選択場面の個別MP4がないこと、保存済み区間の保持、区間の重複・別場面への混在がないことを確認。
- 結果: `test-results/checkpoint-resume/scenes-result.json`。動画・区間一覧: 同フォルダの `outputs/be9c8c65-239a-4dc1-ae4d-da3c8ae9581a/`。

管理画面の選択・改名・場面のみの出力検証（`tests/scenes-ui.mjs`）にも合格。1場面だけを選び「説明用の組み立て」に改名し、全体MP4を作らず個別動画だけを出力・再生できること、および元作品との一致を確認した。結果と画面画像は `test-results/scenes-ui.json`、`test-results/scenes-ui.png`。

## 制限

すべての組み立て操作を実行するため、出力対象を減らしても準備・組み立て時間は省略されない。直接のマウス・キー入力や任意の実行操作を含む独自手順は場面別出力に対応しない。保存地点を持たない過去の動画の後処理による分割は、この機能には含めない。
