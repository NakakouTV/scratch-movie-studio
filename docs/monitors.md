# 変数・リストのモニター

独立カットと個別セッションで、既存データの表示・配置・スクロールを操作できます。通常のsb3再構築ジョブには指定できません。データの作成は従来の`variable.create`を使います。

独立カット画面の「変数・リストのモニター操作」で、読み込んだデータを選び、カット設定を生成できます。必要なら「緑の旗で開始してから撮影」を選びます。リストの場合は指定項目数まで初期化されるのを録画外で待ちます。

```json
[
  {"type":"monitor.show","kind":"list","scope":"global","name":"マスの状態"},
  {"type":"monitor.layout","kind":"list","scope":"global","name":"マスの状態","x":12,"y":50,"width":180,"height":220},
  {"type":"monitor.scroll","kind":"list","scope":"global","name":"マスの状態","index":27,"align":"center","duration":600},
  {"type":"wait","ms":1000},
  {"type":"monitor.hide","kind":"list","scope":"global","name":"マスの状態"}
]
```

|操作|内容|
|---|---|
|`monitor.show / monitor.hide`|公式コードパレットのチェックボックスをクリックします。すでに指定状態なら操作を省略します。|
|`monitor.layout`|表示中のモニターをドラッグ。リストは右下のハンドルでサイズ変更。変数の`mode`は右クリックメニューで切り替えます。|
|`monitor.scroll`|表示中のリストをホイールでスクロールし、指定項目が見えることを確認します。全画面でも使用できます。|

共通の識別は`kind: "variable" / "list"`（省略時variable）、`scope: "global" / "local"`（省略時local）、`name`または`id`です。localの`target`はオリジナルのスプライト名、省略時は選択中の対象。グローバルとローカルに同名データがあっても区別できます。クローン固有のモニターには対応していません。

配置の`x,y`は**480×360のステージ左上が(0,0)、右・下が正方向**です。スプライトの中心基準の座標とは異なります。整数で指定します。リストの`width`は100〜478、`height`は60〜358。外枠2pxを含めた全体がステージに収まる指定が必要です。省略した項目は現在の設定を保ちます。

変数の`mode`は`default`（名前と値）、`large`（値のみ）、`slider`です。largeで名前が消えるのはScratchの標準仕様です。変数の任意の幅・高さは指定できません。リストにmodeは指定しません。

Scratchは全画面での配置・サイズ・表示形式の変更を許可していません。`monitor.layout / show / hide`は必要なときエディタへ戻って操作し、完了後に元の全画面表示へ戻します。ローカルデータの表示切り替えでは対象のスプライトを選択し、表示切り替えではコードタブへ移動します。

スクロールの`index`は1始まりで、存在する項目を指定します。`align`はstart / center / end（既定center）、`duration`は0〜5000ms（既定600ms）です。ブラウザーのホイール反映待ちも含むため、指定時間ぴったりの終了は保証しません。項目を変更する操作ではありません。

非表示、範囲外の番号、他の表示に隠れた操作対象、ステージに収まらない配置はエラーです。実行中の作品がリストや表示状態を変える場合は競合するので、`runtime.wait`で待機するか停止後に配置してください。途中で失敗した操作には、それまでの画面変更が残る場合があります。

状態APIの`monitors`にはID・所有者・表示形式・位置・サイズ・表示状態・値、表示中ならlabelと画面上のbox、リストならscroll（top / height / total / first / last / box）が含まれます。first / lastは少しだけ見える項目も含みます。値が空ならlastは0です。

位置・サイズ・表示状態・表示形式は結果sb3に保存されます。**リストのスクロール位置はScratchのsb3保存対象ではありません。**撮り直す際は保存したカット設定の`monitor.scroll`を再実行します。全画面切り替えや非表示→表示でリスト表示が作り直されることがあるので、スクロール操作はその後に指定してください。

検証: `node tests/monitor-actions.mjs`（Chrome・FFmpegが必要）。ネイティブ操作、全体／ローカル同名リスト、表示形式、配置・サイズ、先頭／末尾／途中のスクロール、重なり・範囲外エラー、sb3保存・再読み込み、MP4、設定作成画面を確認します。
